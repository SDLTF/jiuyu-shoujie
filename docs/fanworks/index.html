图片二创#27

酒不醉人

创作者 琉西法＆酥心糖（Codex)

作品描述

酒馆里的炉火烧得正旺。 酥心糖将一只白瓷酒壶放在桌上，壶身绘着细细的桂花纹。"猜猜这是什么？"小语放下笔记，仔细端详了一会儿。 "酒？这壶倒是很漂亮。" "从东方带来的桂花酒。"酥心糖笑吟吟地说，"我们那儿， 有时候会拿花来给酒起名字。" "所以呢？" "所以我还带来一句家乡的话。" 酥心糖把酒壶向桌子中央挪了挪，托着下巴，忽然将声音放轻。 "酒不醉人，人自醉。" 小语眨了眨眼。 "什么意思？" "就是说呀﹣-"酥心糖故意拖长了声音，"有时候让人心神 不宁的，未必是酒。" 她没有继续往下说，只是笑着望向小语。 小语看了她片刻，终于明白了。 "你是不是在拐着弯说我？" "哎呀，被发现了？" "这有什么难发现的。" 小语若无其事地翻开笔记本，提笔写下一行字。 酥心糖好奇地凑过去。 "写什么呢？" "现场记录。" "记录什么？" 小语将笔记本转过去。 纸上端端正正地写着： 「酥心糖，疑似借东方酒文化实施言语调戏。」 酥心糖愣了一瞬，随即笑出声来。 "那你准备怎么处理？" 小语把笔放下，认真地看着她。 "还没想好。不过，按照学院的规定，证据应该先留着。""那我呢？" "嫌疑人？" "嗯哼？" 小语终于忍不住笑了。 "当然也得留下，配合调查。" 酥心糖微微挑眉。 她原本还想再说些什么，最后却只是托着下巴，看着眼前笑得有些得意的小语。"好呀。" 她轻轻敲了敲桌沿。 "那今晚，我就不走了。" 窗外夜色渐深。 桌上的桂花酒还未动过，两个空酒盏安静地映着炉火。至于究竟是谁先被谁逗得乱了心思，恐怕还要调查很久。
