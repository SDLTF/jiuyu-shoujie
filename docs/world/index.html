世界与守护#

活体边界

亦作：世界边界、环的身体

环的身体本身构成世界边界，完整边界无法被任何人直接穿越。

环是活着的边界本体；九头鸟、神格与九首体系提供维持、隔离接续和修复条件。边界本体与供能体系各有作用。

本体死亡会使整体边界消失，其他世界得以入侵，世界进入危机。局部受伤与本体死亡必须区分。

世界内的旅行、梦路、保持本界联系的局部接合区域和投影参与，不自动等于穿越完整外界边界。门之钥也不能任意越界。

分布在不同故事线、具有循环联系的同一身体。

世界与守护#

边界伤口

亦作：局部缺口、边界受伤

局部边界受损形成的缺口，是异界入侵的危险通路。

归首失败撤去隔离接续，造成环的局部身体受伤并出现缺口；环仍然活着，整体边界尚未消失。

缺口形成后的侵入属于边界失稳的结果，不构成任何人能够正常直接穿越完整边界的例外。

终局由二十七站分授恢复维持条件，小白完成高级边界校准，环按实际进度续接身体、恢复闭合。关闭缺口不以杀死环为代价。
